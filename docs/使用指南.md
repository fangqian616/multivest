## 一、首次启动

双击 `dist/智能多维投资系统.exe`（或 `python desktop.py`）。窗口打开后你会看到：

**顶部五个标签**：行情总览 · 智能研判 · 家庭投资 · 决策记录 · 连接
**右上角两个状态灯**：行情（实时/回退）与大模型（可用/未配置）

### 首次启动会先问你要 API Key

如果数据目录里还没有密钥，界面会在启动 0.6 秒后自动弹出配置窗口：

| 字段 | 说明 |
|---|---|
| API Key | 必填。DeepSeek 或其他 OpenAI 兼容服务的密钥 |
| 接口地址 | 默认 `https://api.deepseek.com`。用 ollama / LM Studio 等本地模型时改成对应地址 |
| 模型 | 默认 `deepseek-chat`，下拉可选 `deepseek-reasoner`、`deepseek-flash`，也可手填 |

点「测试连接」会真发一次请求并把延迟与模型回显报出来；点「保存」立即生效，**不用重启**。
不想现在填就点「稍后再说」，之后点顶栏的 **⚙ 设置** 或右上角的模型胶囊随时能改。

配置写入数据目录下的 `settings.json`（非 Windows 下权限 600）。密钥在界面上只以掩码显示（`sk-ab12••••••••cd34`），不会回传明文，也不进版本库。

### 先确认两个灯都是绿的

- **行情灯**：绿色＝正在用实时行情；黄色＝上游不可用，已回退到内置数据集
  （页顶会出现一条黄色提示条说明原因）
- **模型灯**：绿色＝API Key 有效；红色＝未配置或无效

模型灯红了，点它就能打开配置窗口重填。

> 首次启动约 3~10 秒（要解压内置数据集）。数据会落在 exe 同级的
> `智能多维数据/` 目录里，删掉它会重置所有历史记录。

## 二、每天怎么用

### 早上：看行情总览

打开就是「行情总览」。从上到下的阅读顺序：

1. **KPI 条** —— 涨跌家数、上涨占比、平均涨跌、最强最弱。先看这里判断今天是普涨还是分化
2. **指数瓦片** —— 16 个核心指数，每张带 60 日迷你走势和昨收基准线。
   迷你走势在线之上＝近三个月在涨
3. **当日分时** —— 红色区域在昨收之上、绿色在之下，一眼看出全天强弱
4. **涨跌热力网格** —— 22 个标的按涨跌幅上色，颜色越深幅度越大
5. **K 线** —— 可切换标的，含 MA5/20/60 与成交量
6. **相关性热力图** —— 22×22。**用途是检查分散化**：
   如果持仓里几个标的相关性都在 0.8 以上，那它们其实是一个仓位

> 页顶的自动刷新默认开着（交易时段 15 秒一次）。点右上角可切换成手动刷新。

### 晚上：看智能研判

系统默认每天 **20:30** 自动跑一次（交易日一次，跑过就跳过）。
你也可以随时点「立即研判」手动触发。

跑的时候会有**实时进度**：阶段条显示走到哪一步（采集行情 → 分析师研判 →
提炼争点 → 交叉辩论 → 首席研判官 → 落盘），百分比和子计数同步更新。

**如果超过 150 秒没有进展**，界面会明确说「连接可能已失联」并给你两个按钮
（重新连接 / 放弃本次）—— 不会让你对着一个递增的数字干等。

跑完之后从上往下读：

| 区块 | 读什么 |
|---|---|
| **六维研判** | 雷达图 + 每维评分条。**风险维度分高＝风险环境可控**，分低＝风险偏高 |
| **首席研判官结论** | 建议总仓位与区间，以及理由 |
| **大类资产观点** | 超配/标配/低配 + 信心度 + 依据 |
| **关键分歧** | 看多理由、看空理由、委员会裁决 |
| **投资建议与触发条件** | 每条带优先级和触发条件 —— 条件没到就不动 |
| **风险与观察清单** | 今日风险 + 明日观察点 |
| **当日动量表** | 22 标的的 1/5/20/60 日动量 |
| **风险管理** | 波动状态与仓位乘数（见 [第四节](#四读懂能力边界)） |

### 心情不好时：看决策记录

「决策记录」里所有历史研判与家庭审议都可回溯。**用途是复盘** ——
三个月后回头看当时的判断和理由，比看结果更有价值。

## 三、家庭投资：从建档到方案

### 第 1 步：填家庭档案

「家庭投资」→「家庭档案」。这是唯一需要你输入的地方，分四组：

**基本信息**：城市、家庭年龄、预期寿命、退休年龄
**资产负债表**：房产、存款、投资、贷款余额、房贷月供与利率
**现金流**：税后年收入、年支出、储蓄率、稳定性
**目标与保障**：教育金、养老金、重疾保额、风险测评分数

填完点「保存档案」。**风险承受力雷达**会实时更新，
并据此推导出**权益类资产上限** —— 后续所有方案的硬约束。

> 没有真实数据也可以点「载入示例」先跑一遍看看效果。

### 第 2 步：启动审议

点「启动审议」。系统会跑：

```
五位分析师并行独立研判
   ↓
交叉辩论（看到彼此意见后修正判断，逐条表态）
   ↓
风控委员会对抗性审查（有权否决）
   ↓
配置委员会逐条裁决未收敛的分歧
   ↓
十项确定性硬门禁
```

「审议现场」页会**实时显示**这一切：事件流、收敛曲线、立场矩阵、发言流。
一次完整审议约 1~3 分钟。

### 第 3 步：读配置方案

审议完成后，「配置方案」页给出一份完整的方案：

- **执行总结** —— 六个 KPI + 一段总结，以及本轮辩论是否收敛
- **目标配置权重** —— 权重色条 + 风险资产占比、预期年化、历史最大回撤
- **配置结构与风险收益** —— 环形图（权重）+ 散点图（各大类的历史风险收益，
  星号是本方案）
- **期限分层** —— 短期/中期/长期各占多少
- **情景损益分解** —— 瀑布图，看出哪个品种对回撤贡献最大
- **风险预算** —— **权重 ≠ 风险贡献**。权重小但风险贡献大的就是隐藏敞口
- **再平衡与执行纪律** —— 偏离多少要调、多久检查一次
- **行动清单** —— 具体做什么
- **质量门禁** —— 十项硬校验的通过情况

### 第 4 步：看组合明细

「组合明细」页是执行层面的清单：

| 大类 | 工具 | 权重 | 金额 | 区间 | 历史年化 | 历史波动 | 最大回撤 | 风险贡献 |
|---|---|---|---|---|---|---|---|---|

按着这张表去买就行。**注意「历史年化/波动/回撤」都是真实数据回放的结果**，
不是估算；而类内等权是确定性结果，不是最优化组合。

### 第 5 步：看团队分工（可选，但推荐）

「团队分工」页展示这场审议是怎么运作的：

- **组织结构** —— 五路 → 辩论 → 风控 → 委员会 → 门禁
- **分析师角色卡** —— 每人负责什么、说了什么、对每条议题的立场
- **分组讨论矩阵** —— 行是主张、列是分析师、颜色是支持度
- **立场稳定性** —— 谁在辩论中反复摇摆

> 最后一项值得看：**摇摆的立场对收敛指标贡献的是噪声而不是信号**。
> 如果某个角色每次都在大幅转向，它的打分就不该被同等对待。

## 四、读懂量化预测部分

量化层的结论只应作为参考，**请务必谨慎用于投资决策**。

### 风险管理（主要用途）

系统实测发现：**波动的可预测性显著高于收益的方向**。

- 收益的 20 日自相关 = **−0.007**（不重叠窗口）→ 与 0 无法区分
- 波动的 20 日自相关 = **+0.301** → 约 13 个标准误

所以「风险管理」板块只做一件事：
**用预测到的波动调整总仓位，让组合承担的风险保持恒定。**

界面上会显示：

- **预测未来 20 日波动**（例如 16.8%）
- **当前波动状态**：低 / 中 / 高，以及历史分位
- **仓位乘数**（例如 0.71×）：目标波动 ÷ 预测波动，限幅在 [0.5, 1.5]
- **仓位换算表**：30%/40%/…/80% 各自调整后是多少

**怎么用**：如果你的权益仓位是 60%，而乘数是 0.71，那么可以降到约 43%。
这不是因为它预测会跌，而是因为**现在承担同样仓位，风险比目标高 40%**。

### 模型诊断（要理解）

「量化诊断」板块的五张图给出方向模型在这份数据上的实际表现：

| 图 | 观察 |
|---|---|
| 校准曲线 | 模型说 88.8% 会涨时，实际只有 39.8% 涨了 —— **置信度不宜直接采信** |
| ROC + 分块带 | 曲线贴近对角线 |
| 区间森林图 | 四个模型组合的 AUC 区间**全部横跨 0.5** |
| 分状态 | 只有一个子集区间不跨 0.5，属于探索性结果，**不宜当作发现** |
| 可预测性对照 | 收益 −0.007 vs 波动 +0.301 |

**量化预测部分仅参考，请务必谨慎用于投资决策。** 它的主要用途是风险管理、
分散化检查，以及一个可审计的决策流程。

## 五、手机连接

### 前提

手机和电脑在**同一个 WiFi**。

### 步骤

1. 电脑上打开「连接」页
2. 用手机相机或微信扫页面上的二维码
3. 手机浏览器会打开同一个后端

如果二维码扫不开，页面上会显示局域网地址（形如 `http://192.168.x.x:8760`），
手动输入即可。

### 打不开时逐项检查

1. 手机和电脑是不是同一个 WiFi（不是手机的 4G/5G）
2. 电脑防火墙是否拦了 8760 端口
3. 电脑上「连接」页显示的是不是 `0.0.0.0`（而不是 `127.0.0.1`）

> 手机端三个视图（行情总览 / 智能研判 / 组合明细）都做了适配，
> 底部有导航栏。只支持看，不支持编辑。

## 六、数据与配置

### 数据落盘位置

| 运行方式 | 位置 |
|---|---|
| exe | exe 同级的 `智能多维数据/` |
| 源码 | `backend/daily/`（研判）、`backend/runs/`（审议）、`backend/profiles/`（档案） |

删掉这个目录会重置历史记录（不影响内置数据集）。

### 配置来源与优先级

密钥、接口地址、模型名三者各自独立解析，按下面的顺序取第一个命中的值：

| 优先级 | 来源 | 适用场景 |
|---|---|---|
| 1 | 单次请求显式传入 | 程序内调用 |
| 2 | `<数据目录>/settings.json` | 界面里填的（推荐） |
| 3 | 环境变量 `DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL` | 服务器部署 |
| 4 | `~/.dsh/.credentials.yaml`、项目根目录 `.env` | 开发机复用已有配置 |

配置窗口底部会显示当前生效的来源。改了配置却不生效时，先看这里——
多半是环境变量或凭据文件盖过了界面上的值。

### 可调参数

在 `.env` 里配置：

```bash
MULTIVEST_NIGHTLY_AT=20:30        # 每晚研判时间
MULTIVEST_NIGHTLY_ENABLED=0       # 关掉定时任务
MULTIVEST_DATA_DIR=D:\我的数据     # 自定义数据目录（settings.json 也在这里）
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

### 重建数据集

内置数据集是 2018-06 ~ 2026-09、22 个标的的日频 OHLCV。要更新：

```bash
python tools/fetch_market_data.py --build
python tools/train_model.py          # 数据集更新后必须重训，否则特征对不上
```

> 第二行**不能省**。模型的特征是按数据集算的，数据变了特征就漂了。

## 七、排查问题

### 窗口没弹出来 / 双击后一闪而过

看 exe 同级的 `崩溃日志.txt`。最常见原因是 WebView2 用户数据目录被占用
（反复强杀进程会留下孤儿 `msedgewebview2.exe`）。

**处理**：任务管理器里结束所有 `msedgewebview2.exe`，再启动。

### 研判卡住不动

界面超过 150 秒没进展会提示「连接可能已失联」。点「重新连接」会向服务端确认；
如果服务端确实没在跑，点「重新发起研判」。

服务端单次研判有 **15 分钟硬上限**，超过会自动结束。

### 一直显示「已等待模型响应 N 秒」

说明大模型接口慢或不通。先单独诊断：

```bash
python -c "import sys; sys.path.insert(0,'backend'); from engine.llm import LLMClient; \
print(LLMClient(timeout=30).chat('回复OK', max_tokens=8))"
```

- **正常返回** → 上游是好的，问题在网络抖动，等它重试
- **报 self-signed certificate** → 本机有 TLS 拦截，`pip install truststore`
- **超时** → 上游真的不通，检查 `DEEPSEEK_BASE_URL`

### 行情显示「回退数据集」

实时行情走腾讯公开接口，偶尔不可用。系统会自动回退到内置数据集的收盘价
并在页顶显示黄条。**这不影响研判**，但看到的价格可能是上一交易日的。

### 打包失败

```
当前 Python 没有安装 PyInstaller
```

本机可能有多个 Python。用装了依赖的那个：

```bash
C:\ov\Scripts\python.exe tools\build_desktop.py
```

### 想彻底重来

```bash
# 删掉历史记录（保留内置数据集与模型）
rm -rf backend/daily backend/runs backend/profiles
# 或删掉模型，重新训练
rm backend/data/dataset/model.json && python tools/train_model.py
```
